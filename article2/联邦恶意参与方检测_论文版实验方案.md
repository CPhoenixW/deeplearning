# 实验方法

本文实验用于系统评价两阶段 AE-SVDD 联邦恶意参与方检测方法的有效性。实验重点考察四个方面：不同攻击下的全局模型效用、恶意参与方检测能力、Phase 1 与 Phase 2 的互补作用，以及客户端规模和特征压缩对计算开销的影响。所有实验均通过 `configs/` 中的 JSON 配置、`FedConfig` 字段或矩阵扫描器完成，不通过临时修改训练代码改变实验条件。

## 1. 实验设置

### 1.1 数据集与全局模型架构

为全面评价方法在不同数据模态和任务复杂度下的适用性，实验采用 MNIST、Fashion-MNIST、CIFAR-10 和 AG News 四个数据集。当前代码中的 MNIST 和 Fashion-MNIST 使用相同的灰度 ResNet-18 结构，输入图像统一调整为 32×32；CIFAR-10 使用针对小尺寸彩色图像调整过的 ResNet-18；AG News 使用带有 BatchNorm 分类头的 Transformer 文本分类器，以便在语言任务中提取 LayerNorm/BatchNorm 特征。

MNIST 和 Fashion-MNIST 用于基础图像分类与快速验证，CIFAR-10 用于检验方法在较深视觉模型上的鲁棒性，AG News 用于验证方法从视觉任务向文本任务迁移时的有效性。不同数据集的绝对分类准确率不直接进行高低排名，主要比较防御相对于 FedAvg 的收益、检测指标和额外开销。

由于方法不使用服务器端根数据集、干净验证集或后门触发样本，客户端数据划分会直接影响正常更新的统计分布。主实验设置 IID 和 Dirichlet(α=1.0) 两种环境，其中 IID 用于总体主结论，α=1.0 作为轻度 non-IID 环境因素。α=0.5 和 α=0.1 仅用于环境压力分析，不将其解释为方法能够消除 non-IID。每个任务、客户端规模、alpha 和随机种子的客户端划分在不同攻击与防御之间复用，以保证比较成对公平。

主实验客户端数量设置为 50、100 和 200，恶意比例设置为 10%、20%、30% 和 40%，始终保持良性客户端占多数。50% 恶意比例只用于观察多数良性假设失效时的边界，不进入主结论的平均结果。默认训练轮数为 300，本地训练 epoch 为 1，batch size 为 64，正式结果至少使用 42、43、44 三个随机种子。

### 1.2 攻击方法

实验模拟部分客户端被恶意控制的联邦学习环境。恶意客户端编号固定为最后 `K-num_benign` 个客户端，服务器在运行时不使用这些身份标签；身份标签只用于计算离线检测指标。攻击方法分为模型/梯度级攻击、数据/目标级攻击和混合攻击三类。

**标签翻转攻击（Label Flipping, LF）**：恶意客户端在本地训练时将标签变换为 `y' = C-1-y`，其中 C 为类别数。该攻击改变本地监督信号，主要用于检验方法对数据投毒的处理能力。

**高斯模型投毒（Gaussian, GN）**：恶意客户端以全局模型每个张量的均值和标准差为参考，构造带高斯噪声的上传模型。噪声强度由 `gaussian_sigma` 配置，用于模拟明显的模型级异常更新。

**符号翻转攻击（Sign Flip, SF）**：客户端先进行正常本地训练，再将模型增量乘以负方向上传，缩放由 `sign_flip_scale` 控制。该攻击用于检验方向和符号特征的检测能力。

**LIE/ALIE 攻击（LIE）**：服务器根据良性客户端上传增量的均值和标准差构造统计伪装更新，攻击强度由 `lie_s` 或 `lie_z_override` 控制。该攻击用于检验方法在更新距离不显著异常时的检测能力。

**后门攻击（Backdoor, BD）**：图像任务在部分本地样本右下角写入固定方形触发器并修改为目标标签，同时支持模型替换放大；文本任务采用目标标签投毒。后门实验同时记录干净测试准确率和触发测试集上的 ASR，不能用干净准确率代替 ASR。

**混合攻击（Mixed Attack）**：混合攻击中不同恶意客户端在同一轮分别执行不同攻击，而不是每轮只选择一种攻击。默认组合为 M1（LF+Backdoor+Gaussian），扩展组合为 M2（LF+Sign Flip+LIE）和 M3（LF+Backdoor+Gaussian+LIE）。攻击类型按照恶意客户端编号确定性分配，完整映射写入实验 JSON，便于分别统计各攻击族的检测率。

### 1.3 鲁棒聚合与检测方法

本文将 AE-SVDD 与无防御和当前代码中已经完成统一接口实现的鲁棒方法进行比较。FedAvg（`avg`）作为无防御基线，用于观察攻击造成的性能下降和无攻击时的误伤；Trimmed Mean（`tm`）作为坐标统计基线；Multi-Krum（`mk`）作为距离几何基线；LASA（`lasa`）、FedSECA（`seca`）和 FL-Defender（`fld`）作为已接入代码的代表性方法；FedDMC-style 多视角检测器（`dmc`）融合更新范数、方向、符号、稀疏度和跨轮 EMA 行为。

本文方法记为 `svdd`。Phase 1 使用自编码器重建误差进行鲁棒筛选，Phase 2 使用潜在空间单类中心、动态 MAD 阈值和可信客户端聚合。FLDetector、BRAFL、FLARE、GShield、FLAME、DeepSight 和 FLAD 等尚未统一接入当前代码的方法不纳入数值主表，待完成同一数据、模型、轮数和随机种子下的复现后再加入比较。

### 1.4 评价指标

模型效用使用干净测试集准确率 TACC、测试损失、相对于 FedAvg 的 Accuracy Drop 以及达到目标准确率所需轮数进行评价。后门攻击额外报告 ASR，即触发测试样本被预测为攻击目标标签的比例。

检测能力使用 DAR、DPR、RR、TPR、良性客户端 FPR 和 F1。DAR 表示恶意与良性客户端整体识别正确率，DPR 表示被判定为恶意的客户端中真正恶意客户端的比例，RR/TPR 表示实际恶意客户端被拒绝的比例。连续检测分数由每轮 JSON 中的 `detection_scores` 计算 AUROC 和 AUPRC；当某轮只有一个类别时，该轮 AUC 记为 `NA`。

效率指标包括总墙钟时间、每轮本地训练时间、每轮检测与聚合时间、峰值 GPU 显存、特征维度、通信量和结果文件大小。所有配置至少使用三个随机种子，结果报告均值和标准差；主表使用最后 10 轮均值，同时保留最后一轮和完整逐轮 JSON。

## 2. 实验结果

### 2.1 全局模型性能

#### 2.1.1 主实验结果

在默认设置下，实验遍历四个数据集、六类单一或混合攻击以及 `avg`、`tm`、`mk`、`dmc` 和 `svdd` 防御方法。主设置使用 K=100、恶意比例 30%，分别在 IID 和 α=1.0 环境下进行；K=50/200 以及 10%/20%/40% 恶意比例作为同一实验矩阵中的环境扩展。

主表按数据集分块，报告 TACC、DAR、DPR、RR、FPR 和 AUROC。对于后门和包含后门的混合攻击，额外报告 ASR。主表同时包含无攻击配置，用于确认某种防御不是通过拒绝大量良性客户端获得较低攻击指标。不同数据集的结果不比较绝对准确率，而比较相对于 FedAvg 的准确率保持程度、检测质量和计算开销。

#### 2.1.2 收敛与检测结果

收敛曲线重点展示 CIFAR-10 和 AG News 在 LIE 与 M3 混合攻击下的 TACC 曲线；含后门的曲线同时展示 ASR。检测结果使用攻击类型 × 防御方法的分组结果，报告 DAR、DPR、RR 和 FPR，并绘制每轮客户端保留率和检测分数分布。对于混合攻击，还要按照 LF、Backdoor、Gaussian、Sign Flip 和 LIE 分别统计恶意客户端的 RR，避免总体指标掩盖某一种攻击的失败。

### 2.2 关键因素影响

#### 2.2.1 恶意客户端比例和客户端规模

固定 CIFAR-10、α=1.0、300 轮和 30% 基准配置，分别改变恶意比例 10%、20%、30% 和 40%，比较不同防御的 TACC、RR 和 FPR。50% 仅作为边界点，用于展示多数良性假设失效后的性能变化。随后固定恶意比例 30%，改变客户端数量 K=50、100 和 200，观察检测质量、收敛速度和单轮开销是否随规模变化。

#### 2.2.2 不同程度的 non-IID

固定 K=100 和恶意比例 30%，比较 IID、α=1.0、α=0.5 和 α=0.1。α 越小表示客户端类别分布越不均衡。该实验主要报告正常客户端 FPR、恶意客户端 RR、TACC 以及客户端类别熵和样本量统计，用于说明正常 client drift 对单类检测边界的影响。该实验属于环境敏感性分析，不作为方法能够解决 non-IID 的证据。

#### 2.2.3 攻击强度

通过配置文件改变 `gaussian_sigma`、`sign_flip_scale`、`lie_z_override`、`backdoor_poison_ratio` 和 `backdoor_model_replace_scale`，形成由弱到强的攻击强度序列。结果绘制攻击效果与检测率的关系曲线，并同时报告 TACC、ASR、RR 和 FPR，从而区分“攻击没有成功”和“防御检测并抑制了攻击”。

#### 2.2.4 动态收紧边界

Phase 2 的硬隔离阈值采用 `tau_start` 到 `tau_end` 的线性收紧。实验比较动态收紧和静态阈值两种配置，观察早期误伤、后期漏检、TACC、RR 和 ASR 的变化。该实验只调整配置中的阈值参数，不修改检测流程。

#### 2.2.5 特征压缩维度与服务器开销

由于 ResNet-18 和 Transformer 含有大量参数，AE-SVDD 不直接在原始参数空间计算潜在表示。实验使用固定投影特征，并将维度设置为 `k∈{64,256,1024,4096,8192}`。结果采用双轴图展示压缩维度对 TACC/RR 和每轮服务器检测时间的影响，同时记录显存、特征文件大小和最终 JSON 大小。所有维度均可通过 `param_descriptor_dim` 配置，不需要修改源代码。

#### 2.2.6 两阶段机制与联合效果

为验证两阶段的互补性，固定 CIFAR-10、K=100、30% 恶意、IID/α=1.0，并分别使用 GN、SF、LIE、LF、BD 和 M1。实验包含四种配置：无检测控制（FedAvg）、P1-only（`phase1_rounds=total_rounds`）、P2-only（`phase1_rounds=0`）以及 P1+P2 Full（`phase1_rounds=15`，`phase1_selection=reconstruction`）。P1-only 用于观察重建误差对模型/梯度攻击的识别，P2-only 用于观察不经过预热时潜在中心和聚合的效果，P1+P2 用于检验先筛选可信客户端再进行潜在空间隔离是否优于任一单阶段。

该实验逐轮报告 P1 重建误差、P2 潜在距离、TPR、FPR、保留率、TACC 和 ASR。若 P2-only 降低了 ASR 但检测分数没有形成良恶分离，只能解释为聚合抑制，不能宣称实现了准确的后门客户端识别。
